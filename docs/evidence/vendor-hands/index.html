同一组物体和评价规则，分别切换两种五指灵巧手

Wuji：20 关节 / 手Sharpa：22 关节 / 手10 组 UniLab 实际运行20 段全景与近景录像
现在完成的事情

官方模型加载、双臂装配、关节控制、逐指接触分组和独立重置已接通。每组运行两个环境、500 步、2 秒；环境 0 做手指屈伸，环境 1 保持默认指令。没有执行接近和抓取策略，十组任务的成功判据均未满足

运行使用 UniLab → MuJoCo。安装位根据网格边界作虚拟对齐，未做硬件法兰或承载验证。局部驱动、关节与接触参数保留源模型，但全局步长、积分器和重力补偿采用本项目配置

模型来源与运行命令原有 Allegro 版全部运行摘要
怎么切换

--robot wuji --task G01 选择 Wuji 苹果场景；--robot sharpa --task all 依次运行 Sharpa 五项场景；--robot allegro 继续使用原版。输出保存解析后的完整配置，任务评分 JSON 保持不变

注意：手型数量、外观或关节数不是能力排名。这轮录像验证控制接口，后续还需要适配每只手的抓取控制器
