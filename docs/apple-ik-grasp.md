# 用 IK 脚本抓起苹果

现在可以先不训练策略，用脚本完成 G01 苹果抓取。2026-11-20 已在本地 UniLab 的 MuJoCo 后端跑通：右侧 Wuji Hand 2.2 抓住苹果，抬高约 10.4 cm，保持稳定并通过现有任务评分

这里的 IK 是逆运动学求解器，不是需要训练的模型。给它一个手腕的位置和朝向，它计算机械臂各个关节该转到哪里。手指如何合拢则由预设关节角度控制，IK 本身不会判断怎样抓得牢

## 怎么运行

在仓库根目录执行，使用已经准备好的 `.venv-scene` 和 Wuji G01 场景：

```bash
MUJOCO_GL=egl .venv-scene/bin/python integrations/unilab/run_grasp_scene.py \
  --task G01 --robot wuji --controller ik_grasp \
  --output runs/my-apple-ik --video
```

输出目录需要是新目录，重复执行时换一个名字。如果尚未准备资产，先看 [Wuji 模型与场景说明](wuji-sharpa-hands.md)

终端显示 `success=[True, False]` 是预期结果：环境 0 执行抓取；环境 1 保持初始姿态，作为控制和独立重置检查，未执行抓取

打开 `runs/my-apple-ik/G01/preview.mp4` 看全景，`hand.mp4` 看手部。`evaluation.json` 保存任务结果，`states.json` 保存实际关节、物体状态、动作和动作阶段。物理记录默认开启，输出接触力、接触位置、穿透代理和步进耗时，含义见 [物理记录说明](apple-physics-recording.md)

## 脚本做了什么

动作按“等物体落稳 → 抬高手 → 移到苹果上方 → 下降 → 合拢手指 → 抬升 → 保持”执行，总计 11.2 秒。机械臂的关键位置通过 IK 求解，再用平滑插值生成每一步的关节目标。动作通过 UniLab 的 `env.step` 下发，苹果在仿真中受重力和接触作用运动，执行时没有设置苹果的位置或把它固定到手上

| 内容 | 文件 |
|---|---|
| 机械臂 IK、动作阶段和手指闭合 | `integrations/unilab/grasp_ik.py` |
| 抓取位置、抬升高度、阶段时长、手指目标角度 | `profiles/controllers/G01_wuji_ik.json` |
| UniLab 启动、动作下发、评分、物理记录、视频 | `integrations/unilab/run_grasp_scene.py` |
| 原有任务成功条件 | `tasks/grasp/G01.json` |

要试不同的手指姿态，可以复制控制配置，通过 `--controller-config 路径` 传入。控制配置与任务评分分开，调整动作不需要降低任务门槛。后续接入策略时，可以替换动作生成部分，继续使用现有场景、评分和物理记录流程

## 这次验证到了什么

采用双 X5 机械臂与左右 Wuji Hand 2.2 的虚拟装配，只有右侧执行抓取。后端版本为 UniSim 2.7.1 / MuJoCo 3.11.0，仿真和控制周期均为 4 ms。苹果质量保持 0.18 kg，滑动摩擦系数保持 0.6，没有修改物体参数或评分门槛

| 检查项 | 实际结果 |
|---|---|
| 抬升至少 5 cm、质心速度不超过 5 cm/s、指定手持续接触，连续满足 1 秒 | 通过，首次满足保持要求的时刻为 10.192 秒 |
| 末尾抬升量 / 末尾速度 | 10.40 cm / 0.164 cm/s |
| 运行中是否触发掉落判定 | 否 |
| 右手接触法向力幅值总和峰值 | 17.40 N，不是物体净合力 |
| 右手接触最大穿透代理 | 约 1.06 mm，仅为该求解器的接触诊断值 |
| 开关物理记录是否改变结果 | 两次记录的动作、关节位置/速度、物体位姿/速度逐项完全一致，评分相同 |

第一次抓取曾抬高约 5.7 cm，随后掉落，评分为失败。调整拇指闭合方向、手指闭合角度和动作时长后，第二版通过。第一轮保留在 `runs/apple-ik-20261120-v1/G01`，第二版保留在 `runs/apple-ik-20261120-v2/G01`，记录关闭对照在 `runs/apple-ik-20261120-observer-off/G01`

[查看视频和结果](evidence/apple-ik/index.html)。视频由实际 UniLab 运行记录离线渲染；侧面视频只换了观察角度，没有修改物体运动

新增两项测试检查了 IK 目标可达、动作连续、左手和对照环境不受控制器影响、不可达目标报错。完整场景测试运行 147 项，其中 7 项跳过，其余通过；精简后的两项控制器测试也通过。无仿真依赖的轻量环境运行同一套测试，42 项因缺少相应运行依赖跳过，其余通过

这只是固定初始场景下的一条脚本基线，还没有测随机初态成功率。它依赖仿真提供的苹果初始位置，手指采用预设姿态；换物体、换手型或改变初始朝向后需要重新验证。关节插值不是避障规划，虚拟手腕装配也没有硬件标定。抓取成功可以验证任务执行和记录流程，但不能据此声称接触力准确或其他物理后端也能成功
